A clearer first look at Android apps

Welcome to APK Security Review.

Get a concise, static look at an Android APK’s package details, permissions and selected manifest hardening signals—then use the checklist to improve your own app’s source project.

How to get started → View the GitHub project

Start in three steps

STEP 01

Open the Telegram bot

Find the bot you configured and send /start. The bot menu and reports are in English.

STEP 02

Choose Security Review APK

Send an APK as a Telegram document. The current upload limit is 19 MB.

STEP 03

Review the report

Use the manifest findings and source-project checklist as pointers for an authorized security review.

Important: a review is not a guarantee.

This site and bot provide advisory static inspection. They do not modify or obfuscate an APK, bypass protections, or make an app impossible to reverse engineer. Only submit apps you own or are authorized to inspect.
